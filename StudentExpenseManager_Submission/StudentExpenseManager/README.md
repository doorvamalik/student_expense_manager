# Student Expense Manager

A Python + SQLite command-line application for recording, managing and analyzing student expenses.

## Features
- Add, view, update and delete expenses (CRUD)
- Input validation and error handling
- Analytics by category and month
- Text report generation
- Persistent SQLite storage
- Automated unit tests

## Technologies
Python 3.10+, SQLite3, unittest. No external packages are required.

## Run
```bash
python main.py
```

## Test
```bash
python -m unittest discover -s tests -v
```

## Modules
1. Expense Management / CRUD
2. Validation & Error Handling
3. Analytics
4. Reporting
