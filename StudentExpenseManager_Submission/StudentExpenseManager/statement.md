# Project Statement

## Problem Statement
Students often record daily expenses informally, making it difficult to know where their money is going. This project provides a simple local application for recording and analyzing student expenses.

## Scope
Expense CRUD operations, validation, SQLite storage, category/month analytics, and text report generation. It is a local single-user application.

## Target Users
College and university students who want a lightweight expense-tracking tool.

## High-Level Features
- Add, view, update and delete expenses
- Validate user input
- Store records in SQLite
- Analyze spending by category and month
- Generate a summary report
